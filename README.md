# You Will Never Leave IKEA

A short first-person game about a Saturday at a flat-pack megastore. You only need a lamp. The goal is to get out.

**Play:** open `index.html` in a desktop browser (or the GitHub Pages link for this repo).

## Controls

| Key | Action |
| --- | --- |
| W A S D | walk |
| Mouse | look around (click to capture the mouse) |
| Shift | hurry (costs patience) |
| E | take · sit · read |
| Q | your shopping list |
| M | sound on/off |

Built with [Three.js](https://threejs.org) r160. Everything (furniture, textures, signage, music) is generated in code; there are no asset files.

Unofficial fan parody. Not affiliated with or endorsed by Inter IKEA Systems B.V.
